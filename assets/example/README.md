# 样例（虚构数据）

这里的数据**全是虚构的**，只用来演示格式。你可以直接用它验证流程跑得通：

```bash
cd ..
./split.sh example/已确认明细_样例.xlsx /tmp/试跑
```

跑完看 `/tmp/试跑` 里的产出，就知道正式流程会给你什么。

## 三个文件

| 文件 | 说明 |
|---|---|
| `已确认明细_样例.xlsx` | 第 ④ 步 AI 应该产出的样子。21 列，支出为负、收入为正 |
| `人工调整说明_样例.csv` | 你在确认页写下的说明，AI 拿来当归类依据 |
| `README.md` | 本文件 |

## 这 12 笔覆盖了什么

| 场景 | 笔数 | 看点 |
|---|---:|---|
| 普通支出 | 5 | 餐饮/购物/交通，自动归类 |
| 收入 | 1 | 工资，必须有账户1 |
| 转账 | 1 | **必须有账户1 + 账户2 两个** |
| 人情 / 学习 | 3 | 跨账本，会拆成不同文件 |
| 退款 / 报销 | 2 | **导入不认，会进手工补录清单** |

## 值得注意的几条

1. **转账那笔**（5000）填了账户1 和账户2 两个——只填一个会校验不过。
2. **退款那笔**（88）账本必须和原订单一致，都在「人情往来」。跨账本冲不掉。
3. **报销那笔**（300）分类沿用原订单「交通/火车飞机」，没有塞进「其他」。
4. 金额：支出为负、收入为正（这是中间文件的写法；`split.sh` 会转成导入格式的全正数）。
